# دليل بناء ملف APK وتثبيته على تابلت Samsung

لا تحتاج إلى حاسوب قوي ولا إلى تثبيت أدوات البرمجة: **GitHub يبني ملف APK مجانًا** على خوادمه.

---

## الطريقة 1 (الموصى بها): البناء التلقائي على GitHub

### الخطوة 1 — إنشاء حساب ومستودع
1. ادخل إلى <https://github.com> وأنشئ حسابًا مجانيًا (إن لم يكن لديك).
2. اضغط **New repository**.
3. الاسم: `maktabati` — اختر **Private** (خاص) — لا تضف أي ملف — اضغط **Create repository**.

> اجعل المستودع **خاصًا**: فيه مفتاح توقيع التطبيق.

### الخطوة 2 — رفع ملفات المشروع
1. فك ضغط الملف `maktabati_project.zip` على حاسوبك.
2. في صفحة المستودع الفارغ اضغط الرابط **uploading an existing file**.
3. اسحب **محتوى** مجلد `maktabati` كاملًا (المجلدات `lib` و`test` و`assets` و`tool` و`backend` و`docs` و`.github` والملفات) إلى الصفحة.
4. اضغط **Commit changes**.

> ⚠ المجلد `.github` مخفي في بعض الأنظمة (macOS). إذا لم يُرفع:
> في GitHub اضغط **Add file ← Create new file**، واكتب الاسم `.github/workflows/build-apk.yml`،
> ثم الصق محتوى الملف نفسه من المشروع، واضغط **Commit**.

### الخطوة 3 — انتظار البناء
1. افتح تبويب **Actions** في المستودع. يبدأ «Build APK» تلقائيًا (أو اضغط **Run workflow**).
2. يستغرق البناء نحو **10 إلى 20 دقيقة** في المرة الأولى.
3. ✅ علامة خضراء = نجح البناء. ❌ علامة حمراء = خطأ (انظر «في حالة فشل البناء» أسفله).

### الخطوة 4 — تنزيل ملف APK
1. اضغط على التشغيل الناجح.
2. أسفل الصفحة في قسم **Artifacts** اضغط **maktabati-apk**.
3. يُنزَّل ملف مضغوط فيه `app-release.apk`. فك ضغطه.

## تثبيت التطبيق على تابلت Samsung

1. انقل `app-release.apk` إلى التابلت (كابل USB، أو Google Drive، أو تنزيله مباشرة من GitHub على التابلت).
2. افتحه من تطبيق **ملفاتي (My Files)**.
3. سيطلب Android السماح بـ «تثبيت تطبيقات غير معروفة» لتطبيق ملفاتي: اضغط **الإعدادات** وفعّل **السماح**.
4. اضغط **تثبيت**. إذا ظهر تحذير Play Protect اختر **التثبيت على أي حال** (التطبيق غير منشور على المتجر).
5. يظهر التطبيق باسم **«مكتبتي الصفية»**.

### التحديثات
كل نسخة جديدة موقّعة بالمفتاح نفسه، لذلك **ثبّت التحديث فوق القديم مباشرة** دون حذف التطبيق.
⚠ **لا تحذف التطبيق**: الحذف يمسح كل البيانات من التابلت. قبل أي تحديث مهم أنشئ نسخة احتياطية (الإدارة ← الإعدادات).

### تثبيت الشاشة أثناء استعمال التلاميذ (موصى به)
عند فتح «فضاء التلاميذ» يطلب التطبيق تثبيت الشاشة حتى لا يخرج التلميذ منه.
في Samsung فعّل الخاصية مرة واحدة: **الإعدادات ← الأمان والخصوصية ← إعدادات أمان أخرى ← تثبيت النوافذ**
(قد يختلف المسار قليلًا حسب إصدار One UI).
لإلغاء التثبيت: اضغط مطولًا على زرّي **رجوع** و**التطبيقات الأخيرة** معًا.

## في حالة فشل البناء على GitHub
1. افتح التشغيل الفاشل ← اضغط على الخطوة الحمراء ← انسخ آخر 30 سطرًا من السجل.
2. أرسلها إلى Claude في محادثة جديدة مع ملف المشروع، وسيصلح الخطأ.
   (المشروع كُتب دون إمكانية تشغيله في بيئة الإنشاء، لذلك قد تظهر أخطاء صغيرة في أول بناء.)

## الطريقة 2: البناء على حاسوبك (للمطورين)
المتطلبات: Flutter 3.47 (أو أحدث مستقر)، Android Studio وAndroid SDK، Java 17.
```bash
cd maktabati
bash tool/prepare_android.sh      # ينشئ android/ ويضبط الأذونات والأيقونة والتوقيع
flutter pub get
flutter test                      # الاختبارات
flutter build apk --release       # الملف: build/app/outputs/flutter-apk/app-release.apk
```
على Windows شغّل `tool/prepare_android.sh` عبر Git Bash، أو نفّذ خطواته يدويًا.

## مفتاح التوقيع
المفتاح موجود في `tool/android/maktabati-release.jks`، وكلمة سره داخل `tool/patch_signing.py`.
احتفظ بنسخة منه: بدونه لا يمكن تثبيت تحديث فوق التطبيق المثبت.
لمزيد من الأمان يمكن وضع كلمة السر في GitHub Secrets باسم `MAKTABATI_STORE_PASSWORD`.

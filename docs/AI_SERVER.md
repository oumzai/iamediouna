# إعداد خدمة الذكاء الاصطناعي (توليد الأسئلة)

التطبيق يعمل كاملًا دون هذه الخدمة: يستطيع الأستاذ كتابة الأسئلة يدويًا.
الخدمة تضيف: توليد أسئلة متنوعة من ملف PDF للقصة، وإعادة توليد سؤال، واقتراح معايير الترتيب.

## كيف تعمل (ولماذا هي آمنة)
```
التابلت ──(ملف القصة PDF + المستوى + رمز وصول المؤسسة)──► الخادم الوسيط ──(مفتاح سري)──► Claude API
```
- **مفتاح Claude السري لا يوجد في التطبيق أبدًا**: يبقى في الخادم الوسيط فقط.
- كل مؤسسة لها **رمز وصول** خاص يمكن إلغاؤه في أي وقت.
- **لا يُرسل أي اسم أو رمز مسار أو نتيجة تلميذ**: فقط ملف القصة ومستوى القسم.
  (اقتراح المعايير يرسل أرقامًا إجمالية مجهولة فقط.)

## الخطوة 1 — مفتاح Claude API
1. أنشئ حسابًا في <https://console.anthropic.com> وأضف وسيلة دفع (الخدمة مدفوعة حسب الاستعمال).
2. **API Keys ← Create Key**. انسخ المفتاح (يبدأ بـ `sk-ant-`) واحفظه.
   يُستحسن تحديد سقف إنفاق شهري من إعدادات الحساب.

## الخطوة 2 — نشر الخادم الوسيط على Cloudflare (مجاني في حدود الاستعمال المدرسي)
1. أنشئ حسابًا في <https://dash.cloudflare.com>.
2. **Workers & Pages ← Create ← Create Worker** ← الاسم `maktabati-ai` ← **Deploy**.
3. اضغط **Edit code**، احذف المحتوى، والصق محتوى الملف `backend/worker.js` كاملًا ← **Deploy**.
4. **Settings ← Variables and Secrets** ← أضف:
   | الاسم | النوع | القيمة |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | Secret | مفتاح Claude |
   | `ACCESS_TOKENS` | Secret | رموز المؤسسات، مثال: `school1:Mdn-7Kp2-xQ93-aaa1,school2:Mdn-Lr48-pW21-bbb2` |
   | `MODEL` | Text | `claude-sonnet-5-5` (اختياري) |
5. انسخ عنوان الخادم، مثل `https://maktabati-ai.<حسابك>.workers.dev`.

> رمز الوصول: اختر نصًا عشوائيًا طويلًا (12 حرفًا على الأقل) لكل مؤسسة. ما قبل `:` اسم للتذكير فقط.

## الخطوة 3 — في التطبيق
**الإدارة ← الإعدادات ← خدمة الذكاء الاصطناعي**: أدخل عنوان الخادم ورمز وصول المؤسسة ← **حفظ واختبار**.

## الاستعمال
فضاء القسم ← القصص ← اختر قصة لها ملف PDF ← **توليد بالذكاء الاصطناعي** ←
اختر المستوى والصعوبة وعدد الأسئلة وأنواعها ← تُنشأ **مسودة** ←
راجع كل سؤال (المرجع في القصة يظهر تحته)، عدّل، احذف، أضف، أعد التوليد، أضف الصور ←
**معاينة** ← **اعتماد ونشر**. لا يرى التلاميذ أي اختبار قبل اعتماد الأستاذ.

## اختبار الخادم محليًا (للمطورين)
```bash
node backend/test_worker.mjs     # اختبار دون اتصال حقيقي (يحاكي Claude API)
cd backend && npx wrangler deploy   # النشر بسطر الأوامر بدل لوحة Cloudflare
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put ACCESS_TOKENS
```

# مكتبتي الصفية الذكية — Smart Classroom Library

تطبيق Android (Flutter) لتشجيع قراءة القصص الورقية في المكتبات الصفية بمؤسسات الريادة الابتدائية،
وتقييم الفهم القرائي، وتحفيز التلاميذ، ومساعدة الأستاذ والمدير على التتبع.

> التلميذ يقرأ القصة **الورقية** من مكتبة قسمه، ثم يجيب على التابلت عن أسئلة تكشف هل قرأها وفهمها.

## الفضاءات الثلاثة

| الفضاء | من يستعمله | أهم الوظائف |
|---|---|---|
| **الإدارة** | المدير | إعداد المؤسسة، استيراد لائحة مسار، كلمات سر الأقسام والتلاميذ وبطاقاتهم، لوحة القيادة، التقارير، معايير الترتيب، النسخ الاحتياطي، سجل العمليات |
| **القسم** | الأستاذ (الأستاذ = القسم) | إضافة القصص (غلاف + PDF) وإسنادها، توليد الأسئلة بالذكاء الاصطناعي ومراجعتها، تتبع التلاميذ، تصحيح الأجوبة القصيرة، النتائج الشهرية، شواهد الثلاثة الأوائل |
| **التلاميذ** | التلميذ (يفتحه الأستاذ) | الدخول بالاسم أو رمز مسار + كلمة السر، «قصصي»، «اختباراتي»، «إنجازاتي»، مسح QR، «إنهاء وتسليم التابلت» |

## يعمل دون إنترنت

كل شيء محلي (SQLite داخل التابلت): الحسابات، القصص، الاختبارات، النتائج، الترتيب، التقارير والشهادات.
الإنترنت مطلوب فقط لتوليد الأسئلة واقتراح المعايير بالذكاء الاصطناعي.

## البدء السريع

1. **بناء ملف APK**: اتبع [docs/BUILD_AND_INSTALL.md](docs/BUILD_AND_INSTALL.md) (GitHub يبني الملف مجانًا).
2. **تثبيته على تابلت Samsung**: نفس الدليل.
3. **التجربة**: عند أول تشغيل اضغط «تجربة التطبيق ببيانات وهمية»
   (المدير: `admin123` — كل قسم: `demo1234` — كل تلميذ: `2468`).
4. **الاستعمال الحقيقي**: أنشئ المؤسسة ← «استيراد مسار» ← «الأقسام والتلاميذ» (كلمات السر والبطاقات).
5. **الذكاء الاصطناعي (اختياري)**: [docs/AI_SERVER.md](docs/AI_SERVER.md).

## بنية المشروع

```
lib/
  core/        العربية، الأمان (PBKDF2/AES)، الجلسات، التصميم
  data/        قاعدة البيانات والمستودعات (المؤسسة، الأشخاص، المكتبة، النتائج)
  services/    قارئ XLSX، محلل مسار، التصحيح، الترتيب، التقارير PDF، النسخ الاحتياطي، الذكاء الاصطناعي
  ui/          admin/ teacher/ student/ shared/ widgets/
test/          اختبارات (مسار، التصحيح، الترتيب، الأمان، الواجهات)
backend/       الخادم الوسيط (Cloudflare Worker) + اختباراته
tool/          تجهيز Android (الأذونات، الأيقونة، تثبيت الشاشة، التوقيع)
docs/          الأدلة والتقرير
```

التقرير التفصيلي لما أُنجز وما بقي: [docs/REPORT.md](docs/REPORT.md).
